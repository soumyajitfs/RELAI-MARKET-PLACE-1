================================================================================
       ROLL RATE MODEL - ACCEPTABLE VALUES SUMMARY FOR ALL COLUMNS
================================================================================

  Model Used   : XGBoost (5-Bucket Architecture — one model per DPD bucket)
  Accuracy     : See per-bucket breakdown below
  Target       : next_month_transition (Stay | Roll_Forward | Cure)
  Total Features Used : 57 numeric + 5 categorical (label-encoded)

  ┌─────────┬──────────────────────────────────────┬────────────┬────────────────────────────────────┐
  │ Bucket  │ Description                          │ Task       │ Classes                            │
  ├─────────┼──────────────────────────────────────┼────────────┼────────────────────────────────────┤
  │   0     │ Current (0 DPD)                      │ Binary     │ Stay vs Roll_Forward               │
  │   1     │ 1–30 DPD                             │ Multiclass │ Cure / Stay / Roll_Forward         │
  │   2     │ 31–60 DPD                            │ Multiclass │ Cure / Stay / Roll_Forward         │
  │   3     │ 61–90 DPD                            │ Multiclass │ Cure / Stay / Roll_Forward         │
  │   4     │ 90+ DPD (Absorbing)                  │ Binary     │ Stay vs Cure                       │
  └─────────┴──────────────────────────────────────┴────────────┴────────────────────────────────────┘

  Dataset Split: Temporal 75% Train / 25% OOT | Account-level 85% Fit / 15% Val (within Train)

--------------------------------------------------------------------------------
  OUTPUT TIER
--------------------------------------------------------------------------------

  Column Name  : rag_rating
  Description  : RAG classification based on Roll_Forward probability
                 (Buckets 0–3: probability of Roll_Forward)
                 (Bucket 4: inverted — probability of Cure; higher = better)

  RAG THRESHOLDS BY BUCKET:

  Bucket 0 (0 DPD — Roll_Forward prob):
  Value   | Probability Range     | Meaning                        | Hex Colour
  --------|------------------------|--------------------------------|------------
  Green   | prob < 0.08           | Low roll risk — stable account | #43A047
  Amber   | 0.08 <= prob < 0.20   | Elevated risk — watch closely  | #FB8C00
  Red     | prob >= 0.20          | High roll risk — intervene     | #E53935

  Bucket 1 (1–30 DPD — Roll_Forward prob):
  Value   | Probability Range     | Meaning                        | Hex Colour
  --------|------------------------|--------------------------------|------------
  Green   | prob < 0.20           | Likely to stay or cure         | #43A047
  Amber   | 0.20 <= prob < 0.40   | Moderate deterioration risk    | #FB8C00
  Red     | prob >= 0.40          | High deterioration risk        | #E53935

  Bucket 2 (31–60 DPD — Roll_Forward prob):
  Value   | Probability Range     | Meaning                        | Hex Colour
  --------|------------------------|--------------------------------|------------
  Green   | prob < 0.25           | Manageable — recovery possible | #43A047
  Amber   | 0.25 <= prob < 0.50   | Significant roll risk          | #FB8C00
  Red     | prob >= 0.50          | Likely to worsen               | #E53935

  Bucket 3 (61–90 DPD — Roll_Forward prob):
  Value   | Probability Range     | Meaning                        | Hex Colour
  --------|------------------------|--------------------------------|------------

  Amber   | 0.30 <= prob < 0.55   | High probability of 90+ DPD   | #FB8C00
  Red     | prob >= 0.55          | Near-certain roll to 90+ DPD  | #E53935

  Bucket 4 (90+ DPD — Cure prob, INVERTED):
  Value   | Probability Range     | Meaning                        | Hex Colour
  --------|------------------------|--------------------------------|------------
  Green   | prob >= 0.40          | Recovery likely                | #43A047

================================================================================
 MODEL DETAILS
================================================================================

  Architecture        : 5 independent XGBoost classifiers, one per DPD bucket
  Training Strategy   : Temporal split — 75th percentile month as cutoff
                        Account-level 85%/15% Fit/Val split within Train
                        Early stopping: 30 rounds on Val AUC (binary) / mlogloss (multiclass)

  XGBoost Hyperparameters (shared across all buckets):
  -----------------------------------------------------
  n_estimators        : 500 (with early stopping)
  max_depth           : 5
  learning_rate       : 0.05
  min_child_weight    : 10
  subsample           : 0.8
  colsample_bytree    : 0.8
  reg_alpha           : 0.1
  reg_lambda          : 1.0
  tree_method         : hist

  Per-Bucket Configuration:
  --------------------------
  Bucket 0 : objective=binary:logistic  | eval_metric=auc        | scale_pos_weight=class ratio
  Bucket 1 : objective=multi:softprob   | eval_metric=mlogloss   | num_class=3
  Bucket 2 : objective=multi:softprob   | eval_metric=mlogloss   | num_class=3
  Bucket 3 : objective=multi:softprob   | eval_metric=mlogloss   | num_class=3
  Bucket 4 : objective=binary:logistic  | eval_metric=auc        | scale_pos_weight=class ratio

  Dataset Composition (post Censored removal):
  ---------------------------------------------
  Total rows          : 90,238
  Unique accounts     : 6,146
  Avg snapshots/acct  : ~14.7
  Date range          : 24-month panel

  Class distribution:
  Stay                : 72,461  (80.3%)
  Roll_Forward        : 12,293  (13.6%)
  Cure                :  5,484  ( 6.1%)

  Bucket row distribution:
  Bucket 0 (0 DPD)    : 71,359  (79.1%)
  Bucket 1 (1-30 DPD) :  8,256  ( 9.1%)
  Bucket 2 (31-60 DPD):  4,496  ( 5.0%)
  Bucket 3 (61-90 DPD):  3,199  ( 3.5%)
  Bucket 4 (90+ DPD)  :  2,928  ( 3.2%)

  SHAP Explainability : TreeExplainer — top 10 drivers per account returned by the API
  Output Column       : rag_rating
  Output Values       : Green (#43A047) | Amber (#FB8C00) | Red (#E53935)
