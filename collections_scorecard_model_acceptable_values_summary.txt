MODEL INFORMATION
--------------------------------------------------------------------------------

  Model Name        : Collections Scorecard — Retail Personal Loan Portfolio
  Model Type        : Logistic Regression on WoE-Transformed Features
  Target Variable   : bad6m
                      (1 = account rolls to 90+ DPD or charge-off within 6 months;
                       0 = account self-cures)
  Feature Selection : WoE / Information Value (IV ≥ 0.02, IV < 1.8) —
                      17 features selected from 26 raw input columns

    Where:
      OFFSET = 487.1229   (Base score at 50:1 odds, PDO = 20)
      FACTOR = 28.8539    (Points-to-double-odds factor)
      β₀     = −0.2116    (Intercept)
      Higher score → safer account → lower probability of rolling bad

  Score Scale:
    PDO (Points-to-Double-Odds) : 20
    Base Score                  : 600 at 50:1 Good:Bad odds
    Range                       : 300 – 900

  Explainability:
    SHAP Method : SHAP LinearExplainer applied to WoE-transformed feature matrix
                  (Per-feature marginal contribution to predicted bad probability)

================================================================================
 FINAL MODEL FEATURES
================================================================================

  The following 17 features are used in the final trained model (selected by IV):

    1.  num_on_time_6m              (On-time payment count, last 6 months)
    2.  cibil_now                   (Current CIBIL bureau score)
    3.  num_missed_6m               (Missed payment count, last 6 months)
    4.  avg_pay_ratio_6m            (Avg ratio of amount paid vs. amount due, last 6m)
    5.  current_dpd_bucket          (Current days-past-due bucket: 30 / 60 / 89)
    6.  cibil_change_since_dlq      (CIBIL score change since delinquency onset)
    7.  days_since_last_pay         (Days since most recent payment of any kind)
    8.  ptp_broken_12m              (Promise-to-Pay commitments broken, last 12 months)
    9.  months_in_bucket            (Cycles account has been in current DPD bucket)
    10. contact_attempts_30d        (Outbound contact attempts by collections, last 30d)
    11. salary_credit_regular       (Flag: regular salary credit observed in account)
    12. ptp_kept_12m                (Promise-to-Pay commitments honoured, last 12 months)
    13. num_nsf_6m                  (Non-Sufficient-Fund / cheque-bounce events, last 6m)
    14. num_new_enq_3m              (New bureau enquiries, last 3 months)
    15. cust_initiated_contact_30d  (Flag: customer themselves reached out, last 30d)
    16. rpc_count_30d               (Right-Party Contacts achieved, last 30 days)
    17. num_new_tl_6m               (New tradelines opened, last 6 months)

================================================================================
 SHAP EXPLAINABILITY OUTPUT
================================================================================

  SHAP values are computed via SHAP LinearExplainer on the WoE-transformed feature
  matrix. Each value represents the marginal contribution of that feature to the
  model's log-odds output for a given account.

  All model coefficients are negative (WoE encoding ensures alignment):
  a positive WoE value for a risk-increasing feature produces a negative SHAP
  contribution to the score (i.e. pushes the score down = more risk).
