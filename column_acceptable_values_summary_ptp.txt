         PTP KEPT MODEL - ACCEPTABLE VALUES SUMMARY FOR ALL COLUMNS

  Model Used   : XGBoost (binary:logistic)
  Accuracy     : 88.7% (AUC: 0.9487 | Gini: 0.8973 | KS: 0.7848)
  Target       : ptp_kept (1 = Kept, 0 = Not Kept)
  Total Features Used : 80 numeric + 9 categorical = 122 after encoding

--------------------------------------------------------------------------------
  OUTPUT TIER
--------------------------------------------------------------------------------

  Column Name  : ptp_risk
  Description  : RAG classification based on predicted probability score

  Value   | Probability Range     | Meaning                        | Hex Colour
  --------|-----------------------|--------------------------------|------------
  Green  | prob >= 0.70          | Likely Kept — low risk         | #46fd35
  Amber  | 0.40 <= prob < 0.70   | Borderline — monitor closely   | #f5b400
  Red    | prob < 0.40           | Likely Broken — high risk      | #B71C1C
