 INPUT FEATURES — ACCEPTABLE VALUES
================================================================================

----------------------------------------------------------------------------------------
A. NUMERICAL COLUMNS — LOAN CHARACTERISTICS (Float)
----------------------------------------------------------------------------------------

  Column Name   | Type  | Min        | Max        | Description
  --------------|-------|------------|------------|----------------------------------------------
  LTV           | float | 0.0014     | 1.9841     | Loan-to-Value ratio.
                |       |            |            | Values > 1.0 indicate negative equity
                |       |            |            | (outstanding balance exceeds property value).

  Notes:
    - LTV is the single strongest predictor of LGD in this model.
    - Higher LTV → higher predicted LGD (less collateral coverage).
    - LTV > 1.0 is valid and observed in the dataset (distressed mortgages).
    - Do NOT pass LTV as a percentage (e.g. use 0.75, not 75.0).

----------------------------------------------------------------------------------------
B. CATEGORICAL COLUMN — LOAN PURPOSE (Integer Flag)
----------------------------------------------------------------------------------------

  Column Name   | Type  | Allowed Values | Description
  --------------|-------|----------------|----------------------------------------------
  LoanPurpose   | int   | 0              | Purchase mortgage
                |       | 1              | Refinance mortgage

  Notes:
    - Encoded as binary integer; do NOT pass string labels.
    - Refinance loans (1) show higher predicted LGD than Purchase loans (0),
      reflected in the positive coefficient (0.7898).
