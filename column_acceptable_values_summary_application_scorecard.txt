================================================================================
     APPLICATION SCORECARD – ACCEPTABLE VALUES SUMMARY FOR ALL COLUMNS
================================================================================

  Model Used   : Logistic Regression 
  Score Scale  : 300–900  (PDO = 20, Base Score = 600 @ 50:1 good:bad odds)
  Target       : bad  (1 = 90+ DPD within first 12 months on book; 0 = Good)
  Total Features Used : 28 (mix of numeric, binary flag, and categorical)

  ┌─────────────────────────────┬───────────────────────────────────────────────────────────┐
  │ Component                   │ Description                                               │
  ├─────────────────────────────┼───────────────────────────────────────────────────────────┤
  │ Champion Model              │ Logistic Regression on WoE-transformed features                            │
  │ WoE Bins                    │ Quantile coarse-classing (10 bins); min 5% per bin        │
  │ Variable Selection          │ IV ≥ 0.02 and IV < 1.5 (leakage guard)                   │
  └─────────────────────────────┴───────────────────────────────────────────────────────────┘

  Dataset Split: Stratified 70% Train / 30% Test (random seed 42; production uses OOT)

--------------------------------------------------------------------------------
  OUTPUT TIER
--------------------------------------------------------------------------------

  Column Name  : scorecard_score
  Description  : Scaled credit score (300–900) derived from Logistic Regression
                 on WoE features. Higher score = Lower credit risk.
                 Formula: Score = OFFSET – FACTOR × (β·WoE + intercept)
                 Clipped to [300, 900] before output.

  SCORE-BAND DECISION TABLE:

  Band                | Score Range       | Approval Decision     | Pop. %
  --------------------|-------------------|-----------------------|--------
  B (low risk)        | top 10 percentile | Approve · Prime       | ~10%
  C                   | P35 – P90         | Approve               | ~55%
  D                   | P15 – P35         | Refer to Underwriter  | ~20%
  E                   | P0  – P15 (lower) | Refer to Underwriter  | ~15%
  F (very high risk)  | bottom 15 pct     | Decline               | ~15%

  Scaling Parameters:
  PDO         : 20  (score points to double the odds)
  Base Score  : 600 (score at 50:1 good-to-bad odds)
  Base Odds   : 50.0
  Factor      : PDO / ln(2)  ≈ 28.85
  Offset      : Base Score – Factor × ln(Base Odds)  ≈ 487.12

================================================================================
 MODEL DETAILS
================================================================================

  Architecture        : Logistic Regression (Champion) on WoE-transformed features
                        XGBoost Classifier  (Challenger) on one-hot encoded features
  Training Strategy   : Stratified random 70% Train / 30% Test (random_state=42)
                        Production deployment to use time-based OOT split

  WoE / IV Configuration:
  -------------------------
  Binning method      : Quantile (pd.qcut, 10 bins), duplicates='drop'
  Minimum bin size    : 5% of training sample
  IV threshold        : ≥ 0.02 to enter model (predictive floor)
  IV ceiling          : < 1.5 (leakage guard)
  IV strength bands   : Unpredictive (<0.02), Weak (0.02–0.10), Medium (0.10–0.30),
                        Strong (0.30–0.50), Suspicious (>0.50)

  Logistic Regression Hyperparameters:
  --------------------------------------
  C (inverse reg.)    : 1.0
  solver              : liblinear
  max_iter            : 300
  random_state        : 42

  XGBoost Hyperparameters:
  -------------------------
  n_estimators        : 400
  max_depth           : 4
  learning_rate       : 0.05
  subsample           : 0.8
  colsample_bytree    : 0.8
  eval_metric         : auc
  random_state        : 42

  Dataset Composition:
  ---------------------
  Total rows          : 50,000 simulated applicants
  Train set           : 35,000 (70%)
  Test set            : 15,000 (30%)
  Target bad-rate     : ~15% (approx; logistic generation with noise)

  Class distribution (approximate):
  Good (bad=0)        : ~42,500  (~85%)
  Bad  (bad=1)        : ~7,500   (~15%)

  Score Scaling (300–900 scale):
  --------------------------------
  PDO                 : 20 (score points per doubling of odds)
  Base Score          : 600 (at 50:1 good:bad odds)
  Base Odds           : 50.0
  Factor              : PDO / ln(2)  ≈ 28.854
  Offset              : Base Score – Factor × ln(Base Odds) ≈ 487.12
  Score formula       : Score = OFFSET – FACTOR × (Σ βᵢ·WoEᵢ + intercept)
                        Clipped to [300, 900]

  SHAP Explainability : LinearExplainer (LR champion); TreeExplainer (XGB challenger)
  Output Column       : scorecard_score  (integer, 300–900)
  Decision Output     : Decline / Refer / Approve / Approve-Prime (band overlay)

 PRODUCTION NOTES

                        applications to correct for selection bias.
  3. Monitoring       : PSI on score distribution, monthly bad-rate by score band
                        vs benchmark; alert thresholds at PSI > 0.10 (watch),
                        PSI > 0.25 (redevelop).
  4. Governance       : Champion / Challenger framework; annual revalidation;
                        model risk documentation aligned with SR 11-7 / RBI MRM.
  5. Artefact keys    : lr_model, woe_pipeline (selected_features, woe_maps,
                        binners, scaling, lr_coef, lr_intercept),
                        
  6. Companion Model  : Behavioural_Scorecard_PersonalLoan.ipynb — runs on the
                        existing performing book for limit management, cross-sell
                        prioritisation, and EWS input.
