MODEL INFORMATION
--------------------------------------------------------------------------------

  Model Name        : Behavioural Scorecard – Retail Personal Loan
  Model Type        : Logistic Regression
  Target Variable   : bad12
  Target Definition : 1 = customer goes 90+ DPD within next 12 months from observation date
  Population        : Active personal-loan customers, MOB ≥ 6, currently < 60 DPD
  Feature Selection : WoE / Information Value (IV ≥ 0.02 and IV < 1.8)


  Score Scaling Parameters:
    PDO (Points to Double Odds) : 20
    Base Score                  : 600  (at odds 50:1 good:bad)
    Factor                      : 28.853901
    Offset                      : 487.122876
    Intercept                   : -1.970935

  Explainability:
    SHAP Method : shap.LinearExplainer  (interventional feature perturbation)
                  Per-feature marginal contribution to default probability prediction
