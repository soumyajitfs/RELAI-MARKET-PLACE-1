SSO FLOW:
=========
Login:
  1. User clicks Login → MSAL's loginRedirect() → browser goes to Microsoft
  2. User enters credentials → Microsoft redirects to /auth/callback#code=...
  3. msalReady processes: initialize() → handleRedirectPromise() → exchanges code for tokens (PKCE)
  4. Tokens + account stored in localStorage
  5. window.location.replace('/dashboard') fires BEFORE React mounts (no flash)
  6. Fresh page load at /dashboard → msalReady finds accounts in localStorage → dashboard renders

Logout:
  1. User clicks Logout → clears MSAL cache from localStorage
  2. Navigates to Azure AD logout endpoint with logout_hint (user's email)
  3. Azure AD ends session → redirects to /login

Persistence:
  - Uses localStorage → user stays logged in across browser sessions
  - Token refresh handled automatically by MSAL

DEPLOYMENT STEPS:
=================
Option A: Deploy with server.js (recommended - handles API proxying)
  1. npm install
  2. npm run build
  3. Deploy root folder to Azure App Service via VS Code Azure extension
  4. Set startup command: node server.js
  5. Set app setting: SCM_DO_BUILD_DURING_DEPLOYMENT = true

Option B: Deploy build folder only (requires CORS on backends)
  1. npm install
  2. npm run build
  3. Deploy build/ folder to Azure App Service
  4. Set startup command: pm2 serve /home/site/wwwroot --no-daemon --spa
  5. Add https://relai-marketplace.azurewebsites.net as CORS origin on all 10 backends

For local development: npm run dev (uses react-scripts start with setupProxy.js)
